Privacy, in plain language.

This landing page uses no analytics, tracking cookies, or third-party fonts. Download and checksum links go directly to GitHub, which receives those requests and serves the files.

The installed app captures text only when you invoke its shortcut. It prepares an editable draft and never presses Send. The demo on this page is a prerecorded video, not a live ChatGPT session.

Preparing a draft exposes your text to the real ChatGPT page and its scripts before submission. Website processing and remote retention are outside the app’s control.

Private sessions use fresh browser profiles. Selected-text state is released when the popup closes, but residual browser files may remain. Private mode does not promise complete erasure.
